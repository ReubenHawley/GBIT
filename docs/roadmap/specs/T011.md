**Task** · Feature: #10 (F04) Conformance fixtures and scenarios · Epic: #2 (E1) Graph kernel and conformance suite

## Summary
Encode the 12 scenarios of proposal section 1.3 as failing tests.

## Architecture acceptance criteria served
- AC-05: Transitive impact
- AC-06: Precise selection
- AC-10: Safe fallback
- AC-13: Reproducibility

## Requirements
- One fixture and one test per scenario: isolated method, shared utility, interface change, comment-only edit, rename, deletion, new test, dependency version change, OpenAPI change, test-config change, analyzer unavailable, unknown dynamic relationship.
- Tests call the planner API and assert on selected, fallback and excluded sets.
- Tests are initially red and tracked by trait `Conformance`.

## Acceptance criteria
- [ ] Exactly 12 scenario tests exist and each references its AC ids.
- [ ] Each is red until the corresponding implementation task lands, then green.
- [ ] No scenario is skipped or deleted to make CI pass.

- [ ] Kernel stays language-neutral (no language-specific logic in `Gbit.Core`)
- [ ] Docs updated where behavior is user-visible
