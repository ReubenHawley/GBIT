**Task** · Feature: #18 (F12) Plugin isolation and security · Epic: #3 (E2) Two independent language ecosystems

## Summary
Sandbox plugin processes.

## Architecture acceptance criteria served
- AC-10: Safe fallback

## Requirements
- Default read-only access to the workspace, write access to a scratch directory only.
- No network unless the manifest requests it and policy allows.
- Use OS facilities (bubblewrap/landlock on Linux, job objects/AppContainer on Windows); degrade explicitly and loudly if unavailable.

## Acceptance criteria
- [ ] A test plugin that writes outside scratch or opens a socket is blocked.
- [ ] Missing sandbox support is surfaced in the plan's completeness status.

## Test-first plan

- Escape-attempt plugin tests per OS.
