## Requirements
- Properties: source/target IDs, type, evidence source (static, runtime, build, contract), analyzer ID and version, revision, confidence/completeness, validity scope.
- Confidence distinguishes definite, possible and incompletely observed.
- Validity scope covers build target, platform, runtime, configuration and environment.

## Acceptance criteria
- [ ] An edge without analyzer id/version or revision is rejected.
- [ ] Scope mismatch makes an edge not applicable rather than silently applicable.
