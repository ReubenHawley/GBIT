**Epic** · Phase 3

## Summary
Measure GBIT against reality before anyone relies on it: run full suites beside planned subsets, replay history, inject faults and quantify misses and savings.

## Exit criteria
Empirical missed-regression and wall-clock metrics meet an explicit rollout threshold across representative projects.

## Requirements
- CI wrappers for GitHub Actions, Azure DevOps and GitLab CI.
- Shadow-mode comparison with `gbit verify --full`.
- Historical replay and mutation datasets.
- Metric computation and observability.

## Acceptance criteria
- [ ] Empirical missed-regression and wall-clock metrics meet an explicit rollout threshold on representative projects.
- [ ] Zero confirmed omitted failure-detecting tests during shadow evaluation (a validation target, not a guarantee).
