**Task** · Feature: #17 (F11) Plugin protocol · Epic: #3 (E2) Two independent language ecosystems

## Summary
A reusable conformance kit for plugin authors.

## Architecture acceptance criteria served
- AC-07: Plugin extensibility

## Requirements
- CLI/test harness `gbit plugin test <executable>` exercising initialize, capabilities, analyze and error paths.
- Checks schema validity, determinism, cancellation and completeness reporting.
- Published so third-party plugins can self-certify.

## Acceptance criteria
- [ ] The .NET and Python plugins both pass the kit.
- [ ] A plugin that omits completeness fails the kit.

## Test-first plan
Write these before the implementation:
- Kit run against a known-good and a deliberately broken stub.

- #65 (T035) Implement transport, framing, timeouts and cancellation in Gbit.Protocol
