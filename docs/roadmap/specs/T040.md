**Task** · Feature: #18 (F12) Plugin isolation and security · Epic: #3 (E2) Two independent language ecosystems

## Summary
Do not execute attacker-controlled plugins with privileges.

## Architecture acceptance criteria served
- AC-10: Safe fallback

## Requirements
- Plugins declared in the repository are untrusted on fork PRs.
- Policy: refuse, run sandboxed without secrets, or use only pre-approved pinned plugins.
- Default for fork PRs is pre-approved plugins only.
- Document the threat model.

## Acceptance criteria
- [ ] A fork PR that adds a malicious plugin definition does not execute it.
- [ ] Behavior is covered by a documented decision table.

## Test-first plan
Write these before the implementation:
- Table-driven policy tests.

- #69 (T039) Strip CI secrets from plugin environment
