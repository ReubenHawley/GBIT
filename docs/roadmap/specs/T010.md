**Task** · Feature: #10 (F04) Conformance fixtures and scenarios · Epic: #2 (E1) Graph kernel and conformance suite

## Summary
Define the fixture format used by every conformance test.

## Architecture acceptance criteria served
- AC-05: Transitive impact
- AC-06: Precise selection
- AC-10: Safe fallback
- AC-13: Reproducibility

## Requirements
- Versioned file format (`gbit.fixture/v1`, JSON or YAML) describing base graph, head graph, change set, test inventory, policy and expected outcome.
- Expected outcome lists selected tests, excluded tests, fallback tests and completeness status.
- Loader and validator in `tests/Gbit.Conformance`.
- Fixtures live under `tests/Gbit.Conformance/Fixtures`.

## Acceptance criteria
- [ ] Malformed fixtures fail with a clear message naming the file and field.
- [ ] A sample fixture round-trips through load and serialize unchanged.
- [ ] The format can express every scenario in section 1.3, including deleted and renamed entities.
