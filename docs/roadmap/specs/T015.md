## Summary
Fix the dependency edge catalog and direction convention.

## Architecture acceptance criteria served
- AC-03: Relationship mapping

## Requirements
- Edge types: CALLS, REFERENCES, IMPLEMENTS, IMPORTS, READS, WRITES, DEPENDS_ON, CONSUMES_CONTRACT, EXECUTES, VALIDATES.
- Dependency edges point Consumer -> Dependency.
- Each edge type declares whether it propagates impact in reverse, and whether it is a dependency or a verification observation.
- Verification edges (EXECUTES, VALIDATES) are not interchangeable with dependency edges.

## Acceptance criteria
- [ ] Constructing a dependency edge with reversed semantics is a compile-time or validation error.
- [ ] The catalog is table-driven so new types require no traversal code changes.
