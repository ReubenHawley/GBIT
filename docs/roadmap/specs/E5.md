## Summary
Future direction: grow GBIT from a test selector into a change-impact verification platform that also selects agent evaluations affected by prompts, tools, schemas and workflows. Starts only after E1-E4 are validated.

## Exit criteria
Agent evaluations are selected by changes to prompts, tools, schemas and workflows.

## Requirements
- Agent-native entity types.
- Evaluation datasets and runners.
- Evaluation of hosted and distributed options.

## Acceptance criteria
- [ ] Changing a prompt, tool definition or workflow selects the relevant evaluations.
- [ ] Hosted options are decided from measured need, not speculation.
