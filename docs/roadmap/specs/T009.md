**Task** · Feature: #9 (F03) Contribution conventions · Epic: #1 (E0) Project foundation

## Summary
Standardize how work is reported and reviewed.

## Architecture acceptance criteria served
- AC-13: Reproducibility

## Requirements
- Issue forms: bug report, roadmap task, plugin proposal.
- Pull request template with test-plan checklist and roadmap ID field.
- Config disabling blank issues except security contact.

## Acceptance criteria
- [ ] Templates appear in the GitHub UI.
- [ ] The PR template links the roadmap ID and mentions the test-first rule.

## Definition of done
- [ ] Tests written first and passing in CI
- [ ] No new warnings; `dotnet format` clean
- [ ] Kernel stays language-neutral (no language-specific logic in `Gbit.Core`)
- [ ] Docs updated where behavior is user-visible
- [ ] Merged by squash via a feature branch
