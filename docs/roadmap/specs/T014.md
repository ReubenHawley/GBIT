**Task** · Feature: #11 (F05) Entity and relationship model · Epic: #2 (E1) Graph kernel and conformance suite

## Summary
Define stable, language-neutral entity identities.

## Architecture acceptance criteria served
- AC-03: Relationship mapping

## Requirements
- Proposed ID shape: `<kind>:<scope>/<path-or-name>` (for example `symbol:Pricing/PricingService.Calculate(decimal)`).
- Entity kinds: repository, project, file, symbol, test, contract, resource, package, config, flag.
- IDs are stable across revisions unless the entity is renamed or moved.
- Plugins mint IDs; the kernel treats them as opaque but validates syntax and uniqueness.

## Acceptance criteria
- [ ] IDs round-trip through parse and format.
- [ ] Same entity at base and head resolves to the same ID.
- [ ] Collisions between plugins are rejected.

## Test-first plan
Write these before the implementation:
- Unit tests for parsing, equality and ordering.
