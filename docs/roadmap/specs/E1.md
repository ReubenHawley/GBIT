**Epic** · Phase 1

## Summary
Build the language-neutral graph kernel and the conformance suite that defines its behavior, tests first. This is the core of GBIT: every later epic plugs into it.

## Exit criteria
All language-neutral selection, versioning, deletion, uncertainty and determinism scenarios pass.

## Requirements
- Typed, versioned property graph with provenance.
- Base/head-aware reverse-dependency impact analysis.
- Safety policy: uncertainty widens selection.
- Deterministic, explainable execution plan.

## Acceptance criteria
- [ ] All 12 conformance scenarios from proposal section 1.3 pass.
- [ ] The monotonicity property holds: adding a possible edge never shrinks the selection.
- [ ] Identical inputs produce byte-identical plans.
- [ ] The kernel contains no language- or framework-specific code.
