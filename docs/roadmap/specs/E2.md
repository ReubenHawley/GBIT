**Epic** · Phase 2

## Summary
Prove the kernel is genuinely language-neutral by running two independent ecosystems (C#/.NET with xUnit and Python with pytest) through the identical planner, over a stable plugin protocol.

## Exit criteria
Both ecosystems use the same core planning engine on real repositories with reproducible selected test execution.

## Requirements
- `gbit.plugin/v1` JSON-RPC over stdio and a plugin host.
- SQLite persistence of snapshots, evidence and plans.
- Git change detection and discovery orchestration.
- Analyzer and runner plugins for .NET and Python.
- Working CLI: init, index, plan, test, explain, graph.

## Acceptance criteria
- [ ] Both ecosystems use the same core planning engine on real repositories.
- [ ] Selected tests execute reproducibly through native runners.
- [ ] Each plugin can be installed and upgraded independently of the core.

## Features
- #17 (F11) Plugin protocol
- #18 (F12) Plugin isolation and security
- #19 (F13) SQLite graph store
- #20 (F14) Change detection and discovery
- #21 (F15) C#/.NET analyzer and xUnit runner
- #22 (F16) Python analyzer and pytest runner
- #23 (F17) CLI commands
