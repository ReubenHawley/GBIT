**Task** · Feature: #12 (F06) Versioned graph snapshots · Epic: #2 (E1) Graph kernel and conformance suite

## Summary
Represent and detect how artifacts changed between revisions.

## Architecture acceptance criteria served
- AC-04: Change detection
- AC-08: Incremental updates

## Requirements
- Change kinds: added, modified, deleted, moved, renamed.
- Rename and move carry old and new IDs.
- Unresolved renames are reported as delete plus add with an uncertainty flag.
- Behavioral vs non-behavioral classification supplied by analyzers (for comment-only edits).

## Acceptance criteria
- [ ] A ChangeSet can be built from fixtures and from git (via T044).
- [ ] Renames resolved reliably preserve identity; ambiguous ones expand selection.
