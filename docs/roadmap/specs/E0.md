**Epic** · Phase 0

## Summary
Establish the repository, build, CI and contribution conventions that every later epic relies on.

## Exit criteria
Solution builds and tests run in CI on every push.

## Requirements
- Reproducible .NET 10 solution with pinned SDK and shared build settings.
- CI that builds, tests and format-checks every pull request.
- Documented test-first workflow, ADRs and issue/PR templates.

## Acceptance criteria
- [ ] `dotnet build` and `dotnet test` pass from a clean clone.
- [ ] Every PR runs CI; `main` is protected and squash-merge only.
- [ ] Architectural decisions are recorded as ADRs.

## Features
- #7 (F01) Repository scaffold
- #8 (F02) Build and CI skeleton
- #9 (F03) Contribution conventions
